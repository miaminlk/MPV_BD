# MPV_BD

[![Build](https://img.shields.io/github/actions/workflow/status/miaminlk/MPV_BD/mpv.yml?branch=main)](https://github.com/miaminlk/MPV_BD/actions)
[![Release](https://img.shields.io/github/v/release/miaminlk/MPV_BD)](https://github.com/miaminlk/MPV_BD/releases/latest)

Windows x86_64-v3 版 libmpv，采用 GPL 配置，包含外部音轨向后跳转的同步修复。

## 下载

在 [Releases](https://github.com/miaminlk/MPV_BD/releases/latest) 下载 `mpv-dev-x86_64-v3-*.7z`。开发包包含 `libmpv-2.dll`、导入库和头文件。

## 构建

每日自动构建，也可以在 [Actions](https://github.com/miaminlk/MPV_BD/actions/workflows/daily.yml) 中手动运行 `Daily Build`。
